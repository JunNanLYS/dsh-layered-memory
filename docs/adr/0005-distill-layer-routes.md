# 蒸馏按层独立路由：层内三级解析与分段设置区

背景：Issue #34——蒸馏各层对模型的诉求差异很大（L1 抽取/去重高频要便宜快稳；
L3 画像蒸馏低频大输入可容忍慢首包但要强能力），而现行所有层共用一条全局解析。
回退链（ADR-0004）解决的是"同一任务故障时换通道"；按层路由解决的是"不同任务
从一开始就走不同通道"——两者正交，可组合（每层各自一条完整链）。

决定：

1. **配置形状**：双入口、同一形状——静态 `llm.layerRoutes`（部署 YAML，层键
   l1/l2/l3，值 = 完整链 `{provider, model, reasoningEffort?}`，与 fallbacks
   条目同形）与运行时 `distillLayerChains`（settings 新键，UI 可编辑）。层键
   三键：`l1` 同管 `l1-extract + l1-dedup` 两个调用点（与成本看板按层级归并口径
   同源）；预算键（extract/dedup/l2/l3）是另一套管线阶段词表，不与路由混用。
   每层上限复用 `DISTILL_CHAIN_MAX`；层内去重与档位词表校验同全局链。
2. **层内三级解析**（`resolveLayerRoutes`，纯决策）：某层配了非空层链即**完整
   替换**该层解析（该层主路由与回退都归层链管，全局链对该层不参与）；优先级
   运行时层链 > 静态层链 > 全局解析（运行时链/静态 pin/默认模型 + fallbacks，
   语义一个比特不动）。未配置层零行为变化。分叉点在 callLLM 按 `opts.layer`
   （既有记账参数），管线 8 个调用点零改动。
3. **层链头行必须 provider+model 双显式**（校验参数化
   `validateDistillChain(entries, {requireExplicitHead})`）：层键出现即意图覆盖；
   "双空 = 跟随默认模型"是全局链独有语义，"默认模型 + 自定义回退"的诉求由全局
   `llm.fallbacks` 承担，禁掉双空头消除"层链头跟随哪套全局解析"的歧义。头行
   残缺（手写 YAML 错误）防御性视为未配置、回退全局——配置错误不致该层失产。
4. **pin 与运行时注入**：`effectiveCfg` 把运行时层链注入 `cfg.llm.
   layerChainsRuntime`；pinned（部署锁）时与运行时全局链一并失效——静态层链
   天然穿透（同为部署者静态配置，与 ADR-0004 决定 6"静态链不构成 pin 绕过"
   同源）。档位是全局偏好轴：层链空档位条目/头行回退全局档位解析。
5. **预算放大跟层（D8）**：输出预算 high/xhigh/max ×4 放大的触发档位改
   `layerEffortTrigger`（层链头档位候选 > 全局主路由候选 primaryEffort > 静态
   全局）——层路由后各层档位可不同，放大跟着层走；callLLM 的自动档补放大防线
   用同一触发值，防 ×16 双乘。预算键值与 UI 语义零改（层×路由×预算矩阵明确
   不做，预算只在设置区做展示归组）。
6. **设置区重构为 B 形态分段**（`DistillSettings`，原型三轮肉眼检查定稿）：
   范围分段 [全局默认|L1|L2|L3] + 分段状态点（蓝实心/空心/灰 = 运行时自定义/
   静态 YAML/跟随全局，数据源 `llm-providers` 新增 `layerChains` 块，与解析
   真值同径）+ 解析关系条常驻；全局面板承载"在用：哪些层"标注与输入预算；
   层面板三态 + RouteChainEditor scope 参数化编辑 `distillLayerChains.<层>`。
7. **记账零改动**：`token_cost` 行级已存 layer + provider/model、成功记实际
   服务路由（ADR-0004 语义）——层路由上线后各层实际路由的成本归因自然准确；
   不新增 layer×route 聚合视图（两个一维视图已覆盖，数据侧随时可补）。

组合关系：回退链语义（降级判定/全额超时/取消不降级/档位钳制/全败交会话退避）
对层链原样继承——层链就是"只属于该层的一条回退链"；每层各自一条链时三段链
互不干扰（覆盖层降级绝不落全局链）。
